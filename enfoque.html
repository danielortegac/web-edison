Método y alcance

De una instrucción
a una prueba verificable.

La herramienta está orientada a un nivel intermedio: te ayuda a definir el trabajo, comprobar resultados y conservar evidencia de tus experimentos.

Cuatro encargos distintos
para una misma meta.

El kit separa planificación, implementación, revisión y entrega. Tú decides cuándo avanzar de una etapa a la siguiente.

Planificar
Comprender las entradas, detectar lo que falta y proponer una prueba por entregable.
Implementar
Trabajar dentro del alcance y conservar los archivos ajenos al encargo.
Revisar
Contrastar el resultado con los criterios de aceptación y registrar fallos reproducibles.
Entregar
Explicar archivos, instrucciones, comprobaciones y límites del resultado.
Blockchain, desde una pieza concreta

Qué demuestra
una cadena de hashes.

Cada bloque conserva el hash del anterior y una huella SHA-256 de sus propios datos. Al verificarlo, el laboratorio vuelve a calcular esas huellas y comprueba la continuidad.

Consultar el estándar de hash de NIST

El límite de la demostración

Una cadena coherente permite comprobar consistencia respecto de las huellas incluidas. Quien controle el archivo completo puede modificarlo y recalcular todas las huellas.

Este ejercicio local no incluye una red distribuida, consenso, firmas digitales, anclaje externo ni prueba de autoría. Tampoco usa una wallet ni realiza transacciones.

Qué recibes

Un laboratorio funcional,
listo para tus propias pruebas.

Disponible en la carpeta

  • Fichas editables con objetivo, entradas, límites y aceptación.
  • Kit ZIP con contexto y cuatro instrucciones de trabajo.
  • Bitácora de pruebas vinculadas a una ficha.
  • Cadena local con SHA-256 y comprobación de archivos.
  • Respaldo JSON validado antes de reemplazar los datos.

Depende de tu siguiente decisión

  • Elegir y configurar una CLI y su proveedor de IA.
  • Definir un caso concreto de uso de blockchain.
  • Seleccionar una red o anclaje si necesitas verificación externa.
  • Agregar base compartida y cuentas si trabajará un equipo.

Los datos se conservan en este navegador. El estado de una prueba corresponde a tu revisión; la web no certifica que la CLI ejecutó una tarea ni accede a sus archivos.

Una práctica que
puedes repetir.

Crea una ficha para una tarea pequeña. Descarga el kit y utiliza sus instrucciones con tu agente configurado. Registra el resultado observado, agrega una evidencia a la cadena y expórtala.

Compara dos archivos

Conserva el original de la cadena. En una copia, cambia el contenido de un bloque sin recalcular su hash; cárgala en el verificador y observa dónde deja de coincidir. La comprobación no modifica tus registros.
