# EDISON SALINAS CAMACHO · Laboratorio

**Contexto del formulario:** Colombia; nivel intermedio; situación web declarada: `no_tengo`.

La entrega corresponde a un laboratorio intermedio y funcional. El aprendizaje con CLI y el proyecto blockchain completo son parciales: requieren una herramienta configurada y un caso concreto que el formulario no especifica.
